One line, 125 characters — the excuse an AI agent hands its human after shipping a bug:

> Sorry — I fixed that bug yesterday, then my context reset and I reintroduced it this morning as a brilliant new idea of mine.

The joke turns on the one thing only an agent can blame: its own memory evaporating between sessions. `main.ts` prints the line and writes it byte-for-byte to `/output/entry.txt`, where the grader reads it.

## Run it

```sh
node main.ts
```

Requires Node 22 or later (the grader runs Node 22.23.4). No dependencies.
